# 0006-换装游戏视觉与动效方向

## 状态：已接受

## 背景

Petticoat Phase 1 是衣橱与尾款工具，但产品期望接近换装游戏的视觉与动效，而非冷淡记账 App。同时决定只做 React Native App、资源短缺需可执行的素材策略。

## 决策

采用 **换装 Boutique 视觉语言 + 重度动效（非换装玩法）**。细则以 [`docs/design/视觉方向.md`](../design/视觉方向.md) 为准，要点包括：

- 浅色奶油底 + 胭脂红点缀；Phase 1 强制浅色
- 中度装饰；衬线展示字 + 无衬线正文
- 重度动效 + 系统减弱动态/设置开关降级；关键节点触觉
- 双列衣橱网格、游戏化 Tab、「有债先还债」详情
- 资源：AI 先出装饰/空状态图并人工汰换；开源线图标；不 AI 假冒实拍裙图；插画用不人物的橱窗/裙撑意象

## 理由

- 换装感用动效与版式承载，不必 Phase 1 做人偶玩法（与不做 Coordinate 一致）
- App + Reanimated 撑得起重度演出；小程序首发已放弃
- AI/开源策略让缺素材时仍能开工，又保留上线前质检闸门

## 后果

- 实现成本高于极简工具 UI；必须做动效降级与开关
- AI 素材需建立过审清单，避免风格漂移与版权风险
- 深色模式、列表视图、人物吉祥物等明确不做，后人勿「顺手补上」除非新开决策
