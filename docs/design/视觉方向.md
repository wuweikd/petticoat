# Petticoat 视觉与动效方向（Phase 1）

## 状态：已定（字体文件具体选型可在实现时敲定）

## 气质

换装游戏 / Boutique 娃娃屋式界面语言——柔和装饰感、物品卡「收藏/装备」式反馈；**不是**冷淡效率工具，也**不是**锁死 Sweet 的粉彩乐园。

## 范围边界

Phase 1 **只借视觉与动效**，不做换装人偶、拖拽穿衣或搭配玩法（与「Phase 1 不做 Coordinate」一致）。人偶换装留 Phase 2。

## 产品名

界面中品牌信号为 **Petticoat**（中文可用小裙子）；工程名 icyProfile 不出现在 UI。

## 平台

只做 App（iOS + Android）；**React Native + Expo**；不以微信小程序 / Taro 为首发。

## 明暗与色彩

- **底**：浅色奶油 / 瓷器底（娃娃屋橱窗）
- **主点缀**：胭脂红 / 玫瑰（非芭比粉）
- **动效点缀**：金色微光等可加强（配合重度动效）
- **Phase 1 强制浅色**：不跟随系统 Dark Mode；不做第二套深色主题
- **避免**：整站紫渐变、默认 AI 紫白配、纯黑丝绒作主底

## 动效

- **密度**：重度（换装游戏级）——进场过场、列表/卡片演出、获得感粒子/闪光、关键节点庆祝动画
- **落点**：导航、加入衣橱、到货、分区切换等；表单填写过程保持可读可点
- **降级**：尊重系统「减弱动态效果」；低端机/严重掉帧时粒子与过场降为短 fade
- **设置**：提供「关闭装饰动效」开关（默认开启全特效）
- **触觉**：关键节点轻触反馈（加入衣橱、到货庆祝、结清确认）；不做 Tab 切换全震；关闭装饰动效时一并减弱/关闭

## 字体

- **展示/品牌**：中文衬线（Petticoat / 标题 / 空状态文案）
- **正文/数字/表单**：现代无衬线黑体
- **避免**：全站圆体/手写体作正文
- **待实现时选定**：具体可商用字体文件

## 装饰

- **程度**：中度 Boutique
- 物品卡可有角饰；关键 CTA 可有小装饰
- 列表/网格不每项贴花；花边与闪光留给获得感节点
- 结构上可用细描边、柔角、丝带感分区标题
- **避免**：全屏蕾丝底纹、常驻蝴蝶结墙

## Tab Bar

- **游戏化**：选中态可有小底座/闪光；中间「＋」更大、带饰框，作为录入/收藏主入口
- 保留图标+文字，不用纯图标
- 首页占位：轻「敬请期待」反馈，不假导航到深层

## 衣橱浏览布局

- **主浏览：双列网格**（换装库存感）
- Phase 1 **不做**列表切换
- **无目录图占位**：BaseColor 色块 + Cut 小标签 + 色名/裙名，避免破图
- **三分区切换**：游戏感页签（丝带/底座）+ 切换动效（如翻卡感）；不做左右滑三页为主手势
- **卡片露出**：图（或占位）+ 裙名 + 品牌 + 状态徽标；预订中可角标「待尾款」
- **不进卡片**：定金/尾款金额、截止日期（放详情页）

## 日历页布局

- **主视图：议程列表**（按月分组的待补尾款 / 手动上新提醒）
- 顶部展示待补总额（可数字滚动动效）
- 月历网格为次要或可后置，Phase 1 不强制双模

## 条目详情页

- **有未结清 PreorderRecord**：首屏突出尾款（警报条 + 金额/截止日期），图鉴信息在下
- **无未结清**：上图鉴（大图/占位 + 基础信息），预订历史可折叠在下
- 不拆成「资料 / 预订」双 Tab（Phase 1）

## 图标

- **主方案**：开源线性图标集（如 Lucide）统一 Tab / 设置 / 通用操作
- **AI**：只补关键装饰与空状态大图，不生成整套 Tab 图标
- **避免**：每张图标独立 AI 导致风格漂移

## 空状态

- **结构**：短文案（可带一点游戏口吻）+ **单张**插画 + 一个主 CTA
- **不做**：多段剧情旁白、纯「暂无数据」冷淡空页
- 插画可由 AI 生成，上线前人工汰换；各主页面（衣橱/日历等）各备一张即可
- **意象**：不人物；用衣架、裙撑、珠宝盒、橱窗等物品/空间，保持跨风格中立
- **避免**：固定萌娘吉祥物锁死 Sweet；每页 AI 人物脸不一致

## 资源策略（缺素材时）

- **主策略：AI 先出图，上线前人工汰换**
  - 适用范围：空状态插画、饰框/角饰、分区装饰、品牌展示氛围图等
  - **必须人工过审后再进生产包**：风格一致性、可商用/版权、是否过甜或过噪
  - 目录商品图仍以用户上传 + 显式同意反哺为主，不靠 AI 假冒实拍裙图
- **字体**：不靠 AI；实现时选开源可商用衬线 + 黑体，再写入本文档具体文件名
- **音效**：Phase 1 可不做
- **动效**：以代码（Reanimated）为主，不依赖厚序列帧素材
